# Vevillage — 🌱 채식 습관을 캐릭터로 키우는 라이프스타일 앱

Built with Java, Spring Boot, PostgreSQL, and Flutter.

# 식단 기록으로 캐릭터를 키우고, 채식 상품까지 이어 주는 습관 서비스

채식을 시작하고 싶은 사람이 10일 단위로 식사를 기록하면, 선택한 채소 캐릭터가 자라고 건강 등급과 열매·도감이 함께 쌓입니다. 같은 식단 성향으로 커뮤니티에 기록을 나누고, 검증된 채식 상품을 찾아 장바구니에 담을 수 있는 라이프스타일 서비스입니다.

## 🎯 프로젝트 배경

채식을 시도하는 사람이 반복해서 막히는 지점:
- 의지만으로는 **10일 이상 기록이 이어지지 않는다**
- 비건 여부와 영양 균형이 **한 화면에 같이 보이지 않는다**
- 먹고 싶은 채식 식품을 **식단 성향에 맞게 다시 찾기 어렵다**
베빌리지는 이 흐름을 **식단 기록 → 캐릭터 성장 → 도감·리워드 → 상품 탐색**으로 잇습니다. 기록은 습관의 입력이고, 캐릭터와 열매는 그 기록의 결과입니다.
<br>

## 🏗️ 시스템 아키텍처
```
[Flutter App]
        │
        ▼
[Spring Boot API]
   ├─ 회원 · 온보딩 · 약관
   ├─ 식단 기록 · 식품 검색
   ├─ 챌린지 정산 · 채소 코치
   ├─ 도감 · 마이페이지
   ├─ 커뮤니티
   └─ 마켓플레이스 · 장바구니
        │
        ├── PostgreSQL          회원, 식단, 챌린지, 상품, 커뮤니티
        ├── 이미지 스토리지      프로필 · 식단 · 상품 이미지
        ├── 식품 영양 데이터      공공 식품 DB + 서비스 식품 마스터
        └── 소셜 로그인           회원 식별
```

클라이언트는 화면과 입력을 담당하고, 서버가 챌린지 상태, 성장·건강 등급, 식품 영양, 상품 노출 조건을 계산합니다. 내부 경로와 운영 도구는 이 문서에 적지 않습니다.
<br>

## 핵심 기능

### 1. 10일 채식 습관 챌린지
- 토마토, 브로콜리, 파프리카 중 하나를 선택해 10일 사이클을 시작합니다.
- 식단 기록이 쌓이면 캐릭터는 Baby, Mid, Full로 자라고, 영양 균형은 별도의 건강 등급으로 보여 줍니다.
- 기간이 끝나면 등급이 확정되고 열매가 지급됩니다. 기록이 없는 채로 기간만 지나면 챌린지는 종료됩니다.
- 진행 중에도 현재 단계와 영양 요약을 바로 확인할 수 있습니다.

### 2. 식단 기록과 영양 반영
- 이름·브랜드로 식품을 찾고, 아침·점심·저녁·간식과 섭취량을 기록합니다.
- 기록마다 탄수화물·단백질·지방·당류가 남아, 챌린지 건강 등급과 하루 식단 요약에 쓰입니다.
- 식단 사진과 프로필 사진을 함께 남길 수 있습니다.

### 3. 채소 코치
- 성장형 챌린지와 별도로, 코치 캐릭터와 10일 목표 끼니를 정합니다.
- 목표 끼니를 채우면 뱃지가 쌓이고, 같은 코치를 다시 완주하면 뱃지가 누적됩니다.
- 두 도전은 동시에 진행되지 않습니다.

### 4. 도감과 마이페이지
- 정산된 캐릭터의 최고 성장·건강 기록이 도감에 남습니다.
- 마이페이지에서 열매 잔액, 완료한 챌린지, 최근 캐릭터, 키·몸무게·식단 성향을 확인합니다.

### 5. 마켓플레이스
- 대체육, 대체유제품, 간편식, 베이커리, 간식 등 카테고리와 식단 유형으로 상품을 탐색합니다.
- 관심 상품은 장바구니에 담고, 구매는 외부 판매처에서 이어집니다.
- 사용자에게 보이는 상품은 검수를 통과한 공개 상품입니다.

### 6. 커뮤니티
- 토픽별 피드에서 글을 작성하고, 댓글과 좋아요로 반응합니다.
- 내가 쓴 글만 따로 볼 수 있습니다.

### 7. 온보딩
- 최초 진입 시 서비스 이용에 필요한 약관 동의와 식단 성향·프로필 설정을 마칩니다.
- 선택 동의는 이후 설정에서 철회할 수 있습니다.

## 📊 데이터

- **식품 영양**: 공공 식품 데이터베이스와 서비스용 식품 마스터를 함께 사용합니다. 검색·상세에서 제공량과 영양 정보를 내려 주고, 식단 기록 시점의 값을 챌린지 계산에 사용합니다.
- **상품 정보**: 상품명, 브랜드, 카테고리, 식단 유형, 이미지, 판매처 링크를 서비스 기준으로 관리합니다. 공개 전 검수는 운영 도구에서만 처리합니다.
- **회원 기록**: 식단, 챌린지 결과, 도감, 커뮤니티 글, 장바구니는 회원 단위로 저장합니다.

원본 데이터, 시드, 운영 검수 기준은 저장소 밖에 두지 않습니다.

```
vevillage-business/
├── domain/
│   ├── challenge/        # 채식 습관 챌린지, 식단 기록, 정산

│   ├── community/        # 토픽, 피드, 댓글, 좋아요
│   ├── marketplace/      # 상품 탐색, 장바구니
│   ├── media/            # 프로필·식단 이미지
│   └── terms/            # 약관 동의
├── member/               # 프로필, 마이페이지
└── login/                # 회원 인증
```
